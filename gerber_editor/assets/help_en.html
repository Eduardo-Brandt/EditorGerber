Editor Gerber

Getting started · version {{version}}

Open the board layers, inspect their overlap, edit in 2D and review the result in 3D. You can keep this help window open while working.

First steps

  1. Open the Gerbers from File or press {{file.open}}.
  2. Activate a layer in the manager on the right; press {{view.fit}} to fit the board.
  3. Select and edit objects, import artwork or draw shapes.
  4. Review in 3D with {{view.3d}} and save your work from File.

1. Files and saving

File → Open Gerber accepts multiple files, including files without extensions. Open Gerber folder loads recognized files from the selected folder. The auxiliary fp-info-cache file is ignored.

You can also drag one or several files from your file manager onto the editor window. They are added to the open layers, with progress in the status bar. Gerbers with or without extensions and Excellon files are supported.

The status-bar progress advances after each file is processed during batch opening. .drl/.xln (Excellon) files with an M48 header also open, including holes and slots in millimetres or inches. Units must be declared; coordinates without a decimal point require an explicit format declaration.

Save writes the active layer. Save as lets you choose a destination and output mode. Preservation keeps original commands when possible; Normalized emits the layer geometry again. Output is validated before being written.

The editor asks before replacing an original Gerber. An asterisk beside a layer name indicates unsaved fabrication changes.

Save all files, in the File menu and top toolbar, writes layers with unsaved changes or no saved file. Choose destinations for new layers before starting. A warning explains that saving may take time and lets you review destinations, including originals to be replaced. The bottom progress bar advances after each file is saved and validated. A failure stops the batch and reports how many files were saved; remaining layers stay pending.

Excellon drilling can be saved as .drl or converted to .gbr using Save as. Preservation keeps unmodified Excellon bytes. Edited drill data is emitted in millimetres with decimal coordinates and validated by reopening. Excellon supports circular tools, holes and slot paths; use Gerber for filled shapes or Clear polarity.

Close all files also has a top toolbar icon and asks about unsaved changes before closing. Use Help → Report problems to open the form in your browser.

Session data: selection groups and editable vector text remain available during the session. Saving retains the fabrication geometry; closing and reopening the Gerber does not restore selection groups or editable text content.

2. Layers and functions

Click a layer name in the manager to activate it. It appears in front of other layers while active. The Move up/Move down buttons organize inactive layers.

Use the checkbox to show or hide a layer. Double-click its name for Color, Opacity and Function options. The × button closes the layer.

FunctionMeaning
F.Cu / B.Cu / InN.CuTop, bottom or inner copper.
F.Silk / B.SilkTop or bottom silkscreen.
F.Mask / B.MaskSolder mask openings.
F.Paste / B.PasteSolder paste.
Edge.Cuts / Route.CutsBoard outline and cutouts/slots.
Drill / Drill.PTH / Drill.NPTHThrough holes and slots supplied in Gerber format.

The editor prioritizes the function declared in Gerber X2 data. Otherwise, it uses the filename/extension. For example, olc means top copper, srlc top silkscreen and fur drill data. You can correct Function manually.

3. Navigation and selection

  • Mouse wheel: zoom at the cursor.
  • Hold the middle button: pan the view.
  • {{view.fit}}: fit all visible layers.
  • Click: select an object or group. Ctrl+click adds/removes it from the selection.
  • Drag a window left to right: select fully enclosed objects. A group must fit entirely inside.
  • Drag right to left: select crossing objects; touching one member selects the whole group.

Select active layer only restricts selection to the chosen layer. The Properties panel describes the selection and offers editing for supported object types.

4. Grouping and ungrouping

Imported artwork is grouped automatically. Click any part to select the whole image, then move, copy or delete it as a unit.

  1. Select two or more objects on the same layer.
  2. Choose Edit → Group objects or press {{edit.group}}.
  3. To separate the components, select the group and choose Ungroup objects or press {{edit.ungroup}}.

Grouping and ungrouping support {{edit.undo}} / {{edit.redo}}. Copies receive independent groups, so selecting the original does not select its copies. Vector text remains editable as text during the session.

Groups organize selection during the session. They do not change fabrication objects or add grouping data to Gerber output.

5. Moving, copying and editing

The Edit menu commands also have icons in the top toolbar, between file and view controls. Hover over an icon to see its name and shortcut. Disabled buttons appear gray.

Disabled or read-only fields also appear gray. Read-only fields still allow selecting and copying content where applicable; use Edit properties to change an object's parameters.

Select an object or group and press {{edit.move}} to move it with the cursor. Click to place; Esc or right-click cancels the preview. You can also click and drag a selection.

{{edit.copy}} copies, {{edit.cut}} cuts, and {{edit.paste}} pastes with the cursor. {{edit.duplicate}} prepares a duplicate. {{edit.delete}} deletes the selection. {{edit.undo}} undoes and {{edit.redo}} redoes an operation.

Paste, duplicate, mirror copy and Move attach the lower-left corner of the selection to the cursor, including stroke width and pad extents. Mirrored copies recalculate this corner after reflection. Clicking commits the preview position, respecting snap. Direct dragging keeps the point where you grabbed the object as its reference.

Edit → Move by offset accepts exact X/Y offsets. Mirrored copy reflects across X, Y or both. Copy array distributes copies in rows/columns or around a center.

Double-click an object to open compatible properties. Text created during this session can be changed in the text dialog. Ungroup imported artwork before editing its components separately.

6. Importing images

Choose Tools → Import black-and-white graphic or press {{tool.import_graphic}}. PNG, JPG, BMP, TIFF and WebP files are supported.

  1. Set the physical width, pixel resolution and black/white threshold.
  2. Check the preview. Black creates geometry; white/transparency leaves an empty area. Use Invert when needed.
  3. Keep Place with mouse checked and confirm.
  4. The preview follows the cursor. Click to place the image center.

For coordinate placement, uncheck Place with mouse and enter the lower-left corner X/Y. The import enters history only after placement. Artwork retains width, aspect ratio and polarity, is grouped, and can be undone as one operation.

7. Shapes, text and dimensions

Activate a visible layer, then select a tool from the left panel or Tools menu.

Enable Filled in the parameter toolbar for solid circles, squares and rectangles. A filled arc creates a circular sector, closed by its two radii. Select a shape and open Edit properties (E) to change it later.

To edit multiple compatible objects, select them and open properties. Check only the fields to apply; changing a value checks its box automatically. Multiple values indicates differing values. Changing only Radius or Thickness keeps centers, positions and other parameters individually.

Edit → Copy array also has a top toolbar button. For a rectangular array, set rows, columns and X/Y spacing. For a polar array, set count and total angle. Enable Define polar array by radius to set the radius and direction of the center relative to the original; the original stays in place. At 180°, the center is to the left. Counts include the original: 4 positions create 3 copies. You can also pick the center with the mouse or enter its coordinates, and choose whether objects rotate with the array.

  • Line: click its start and end.
  • Arc: click the center, start and end direction. Clockwise arcs are available in the menu.
  • Circle: click the center and a point on its edge.
  • Rectangle/square: click two opposite corners.
  • Text: click the insertion point, then set content, font, height and orientation.
  • Dimension: indicate two measured points and the dimension position.
  • Measure distance: click two points; the ruler displays distances without adding geometry.

Dark adds and Clear subtracts areas in object order. Shift constrains direction to 45° or 90°, depending on Ortho. Grid snap and point snap can be configured independently.

8. Fiducials and cutouts

Insert fiducial sets position, copper diameter, mask opening and board side. Required layers are created when needed.

Select shapes and use Cutouts and slots from selection to use stroke width or a closed profile as a cut. Route.Cuts identifies cut geometry used in 3D. You can also use New cutout layer to draw it directly.

9. The 3D viewer and export

Choose View → 3D viewer or press {{view.3d}}. After a 2D edit, return to the 3D window to update the board. Update PCB requests another check of the data.

The bottom bar shows percentage progress through preparation, drilling, composition and meshing, for initial generation and updates. Percentages describe completed stages and do not predict remaining time.

  • Drag: orbit. Middle/right button pans. The wheel zooms.
  • Use Top, Bottom, Isometric, Front and Right views. Home fits and F flips the board.
  • PCB thickness sets board thickness. 3D detail offers Fine, Normal and Fast.
  • Realistic changes lighting; Perspective switches projection.
  • The materials list hides the substrate or surfaces to reveal other layers.

Edge.Cuts supplies the actual outline. Without it, the viewer reports a rectangle estimated from layer bounds. Drill / Drill.PTH / Drill.NPTH in Gerber or Excellon format cut through holes and slots, even when hidden in 2D. Drillmap is an auxiliary drawing. Blind/buried holes still require a stackup unavailable in this version.

The 3D File menu exports JPG, WRL and colored STEP. Choose the JPG resolution. Models use visible materials; STEP is disabled when its support is unavailable in the installation.
